# داده‌های نمایشی کلبه وینتیج

این داده‌ها **ساختگی اما باورپذیر** هستند و فقط برای بررسی و نمایش سایت در محیط توسعه ساخته می‌شوند. نام‌ها، سفارش‌ها، موجودی، نظرها و پرداخت‌های نمایشی را به‌عنوان فعالیت واقعی کسب‌وکار گزارش نکنید. اجرای seed در محیط production و test غیرفعال است.

## اجرای سریع

از پوشهٔ `backend`، دستور `npm run demo:stack` را اجرا کنید. این دستور پایگاه‌دادهٔ موقت PGlite، مهاجرت‌ها، مدیر اولیه، API و seed را آماده می‌کند. در ترمینال دیگر از ریشهٔ پروژه `npm run dev -- --host 127.0.0.1` را اجرا کنید و `http://127.0.0.1:5173` را باز کنید. با بستن demo stack، پایگاه‌دادهٔ موقت از بین می‌رود؛ اجرای بعدی دوباره آن را می‌سازد.

برای پایگاه‌دادهٔ توسعهٔ خودتان، پس از migrate و bootstrap مدیر، `NODE_ENV=development npm run seed:local` را با `DATABASE_URL` و سایر متغیرهای معمول بک‌اند اجرا کنید. این seed صریح و قابل تکرار است و محتوای ویرایش‌شدهٔ موجود را بازنویسی نمی‌کند.

## پوشش

- ۱۱ محصول خرده‌فروشی در هر ۶ دسته، با قیمت ریالی، رنگ/سایز، موجودی ثبت‌شده از WMS و تصاویر پوشاک؛ ۲ محصول عمدهٔ متعلق به ۲ کارگاه تأییدشده.
- ۴ حساب خریدار آزمایشی، ۵ سفارش و فاکتور، پلن عضویت عمده، کوپن، جشنواره، تیکت و اعلان.
- ۴ نظر تأییدشدهٔ آزمایشی. چون سفارش‌ها پرداخت درگاهِ تأییدشده ندارند، این نظرها «خرید تأییدشده» تلقی نمی‌شوند.
- صفحهٔ اصلی و صفحات درباره/وایب از CMS، تصویر هیرو و تمام دسته‌ها، ۴ مقالهٔ فارسی منتشرشده با تصویر شاخص. مجلهٔ ویترین نوشته‌ها را از API عمومی می‌خواند.

حساب‌های نمونهٔ محلی: `seed.customer@kolbe.ir` / `Seed-Customer-123456` و `seed.supplier@kolbe.ir` / `Seed-Supplier-123456`. سایر حساب‌های نمایشی با آدرس `demo.*@example.test` فقط برای ایجاد دادهٔ متنوع هستند. رمز مدیر محلی پیش‌فرض `ChangeMe-Admin-123456` است؛ این مقادیر برای production نیستند.

تصاویر نمونه از URLهای Pexels که در کاتالوگ پروژه استفاده می‌شوند خوانده می‌شوند؛ بنابراین نمایش عکس‌ها به اتصال اینترنت وابسته است. تصاویر افزوده‌شدهٔ [کفش](https://www.pexels.com/photo/brown-leather-loafers-18054235/)، [بافت](https://www.pexels.com/photo/a-person-in-beige-knitted-sweater-holding-yarns-5788999/) و [کیف](https://www.pexels.com/photo/photo-of-a-leather-handbag-27100523/) از Pexels هستند. این‌ها عکس همان کالای قابل فروش نیستند؛ برای موجودی واقعی باید با عکس محصول واقعی جایگزین شوند.

## بررسی

پس از بالا آمدن سایت و seed، از پوشهٔ `backend` با Chrome نصب‌شده `KV_CHROME_PATH=... node scripts/demo-content-smoke.mjs` را اجرا کنید. این بررسی تعداد رکوردها، موجودی و عکس کاتالوگ، پوشش هر دسته، جدا بودن کالای عمده از ویترین خرده، و بازشدن مقاله از UI را کنترل می‌کند.
