# پرو مجازی با API آلفا

بخش «پرو مجازی» اکنون عکس کاربر و عکس محصول را به مدل `qwen-image-edit` آلفا می‌فرستد، وضعیت ساخت را هر چهار ثانیه پیگیری می‌کند و تصویر خروجی را نشان می‌دهد. مدل `flux-dev` فقط متن به تصویر است و ورودی عکس برای پرو لباس ندارد؛ این انتخاب بر اساس [مستندات رسمی آلفا](https://api.appalpha.ir/docs) است.

## راه‌اندازی

کلید را فقط در محیط بک‌اند با نام `ALPHA_API_KEY` تنظیم کنید. برای اجرای محلی می‌توان آن را در `backend/.env` گذاشت؛ این فایل در Git نادیده گرفته می‌شود. کلید را در متغیرهای `VITE_*`، کد فرانت‌اند یا فایل‌های commit‌شده قرار ندهید.

از `backend` دستور `npm run demo:stack` و از ریشهٔ پروژه `npm run dev -- --host 127.0.0.1` را اجرا کنید. در سایت وارد حساب مشتری شوید، «پرو مجازی» را باز کنید، محصولی انتخاب کنید و عکس JPG/PNG/WebP تا ۵ مگابایت بفرستید. عکس کاربر در پایگاه‌دادهٔ کلبه ذخیره نمی‌شود، اما برای پردازش به آلفا فرستاده می‌شود؛ رابط پیش از ارسال رضایت کاربر را می‌گیرد. آدرس تصویر خروجی ممکن است موقت باشد و باید زود ذخیره شود.

ساخت تصویر از اعتبار حساب آلفا مصرف می‌کند. شروع درخواست به ورود کاربر نیاز دارد و به سه درخواست در ساعت برای هر IP محدود است. نتیجه شبیه‌سازی تصویری است و دقت اندازه یا تن‌خور واقعی را تضمین نمی‌کند.
